# 素材授权台 · 设计说明

> 新增模块：`server/`（API + 关系库 + 领域核心）、`licenses.html`（控制台）、`js/licenses.js`。
> 本文档说明关键设计决策，尤其是**校验机制的组合**与**撤回语义**。

## 1. 身份模型：授权记录与内容去重分离

```
blobs(content_hash PK)            ← 内容去重身份：相同文件摘要只存一份，无授权语义
assets(id PK, content_hash FK)    ← 来源身份：不同来源登记 = 不同行，即使摘要相同
licenses(asset_id FK, …)          ← 授权记录：只挂在 asset 上，绝不挂在 blob 上
```

**相同文件摘要不意味着不同来源的授权相同。** 图库采购的图片与作者直传的同一文件，
是两条 `assets` 记录、两套授权；存储层通过 `blobs` 去重，授权层互不影响。
撤回 A 来源的授权时，影响计算沿「A 的授权链」走，绝不会误删 B 来源的引用。

## 2. 关系库：依赖链

```
assets ──< derivatives（派生裁图，授权链向上追溯到原素材）
assets/derivatives ──< refs（正文引用：页面 + 依赖用途 + 状态）
assets/derivatives ──< exports（导出物：授权快照 + 已分发次数）
```

- 每条 `refs` 记录声明它**依赖的用途**（如精选位依赖 `featured`，下载按钮依赖 `download`），
  撤回某用途时只影响依赖该用途的引用，其他用途的引用不受影响。
- `exports.snapshot` 记录启动时刻各目标的授权判定，用于事后解释「启动时是合法的」这一事实。

## 3. 校验机制：发布时一次校验 vs 访问时持续校验

| 维度 | 发布时一次校验 | 访问时持续校验 |
|---|---|---|
| 时机 | 内容发布瞬间 | 每次访问 |
| 一致性 | 强（同步拒绝） | 取决于实现成本 |
| 成本 | 一次 | 每次访问都全量重算则过高 |
| 授权事后变化 | **感知不到** | 能感知 |

单用任何一种都有缺口：只查发布时，撤回后旧页面仍在展示；只查访问时，全量重算太贵。
因此组合成**有明确缓存时限的机制**：

1. **发布时一次校验**（`publish_ref`）：同步判定，不通过即拒绝，结果落审计。
2. **访问时校验 + 明确 TTL 缓存**（`render_page`）：判定结果写入 `validation_cache`，
   普通页 **TTL 300s**、精选页 **TTL 60s**（精选页要求更快停止引用受限素材）。
3. **事件驱动失效**：撤回用途 / 授权到期 / 替图 / 补凭证时，立即删除相关页面缓存并执行
   **撤下**（`refs.state → taken_down`）与**重新生成**（`exports.state → stale` + 持久任务），
   **不等 TTL**。
4. **周期兜底**（sweeper）：到期不是事件，由周期任务扫描 `valid_until <= now` 的授权，
   走同一条覆盖丧失管线。

效果：事件路径下受限内容**立即**停止展示；即使事件丢失，最坏也在
「TTL + sweeper 间隔」内被访问时校验拦下。

## 4. 撤下、CDN 与无法远程收回的事实

- 撤下在**访问层**执行（渲染判定 + 引用状态），**不依赖 CDN 刷新**；
  同时登记 `cdn_purges`（pending → confirmed），因为旧对象可能仍在 CDN 缓存中。
- 已完成且**已被下载**的导出物无法远程收回。系统在审计与
  `/api/reports/unrecoverable` 中记录事实：「受限前已被下载 N 次，已分发副本无法远程收回」。
- **系统不自动推断法律结论**：所有记录只陈述区间、凭证、次数等事实，
  是否产生法律后果由人工评估（导出物异常也只标记 `needs_review`）。

## 5. 提醒：持久任务 + 幂等重试

- 提醒（授权临期 7 天、来源证据缺失、导出复核、重新生成）都是 `tasks` 表中的**持久任务**。
- 每个任务有**幂等键**（`dedup_key UNIQUE`，如 `expiring:{license_id}`），
  sweeper 重试、服务重启后重复运行都**不会重复生成待办**（`INSERT OR IGNORE`）。
- 条件消失（续期、补凭证）时，对应待办自动关闭并留审计。

## 6. 关键场景行为

| 场景 | 行为 |
|---|---|
| 授权续期 | 延长区间 → 临期待办自动关闭；已撤下引用需显式「重新发布」（撤下是粘性状态） |
| 来源证据缺失 | 发布时校验拒绝 + 生成持久待办；补凭证后待办关闭、可发布 |
| 并发替图 | `assets.version` 乐观锁 CAS：基于同一版本的并发替图只有一个成功，另一个 409 |
| 到期时正在导出 | 启动时存授权快照；完成时重新校验，发现已到期 → `needs_review`，不分发 |
| CDN 旧对象仍在缓存 | purge 登记并跟踪确认；确认前访问层已拦截；时间窗全程留审计 |
| 精选页引用受限素材 | 事件驱动失效 + 60s 短 TTL，及时停止引用 |
| 旧下载无法远程收回 | 报告与审计记录下载次数等事实，不下法律结论 |
